# Publication sur GitHub — plan 52

> **Pour les agents :** exécution en ligne, tâche par tâche, tests d'abord. Reprendre à la première tâche non cochée.

**But :** MacDock s'installe sur tous les PC de l'utilisateur depuis un dépôt GitHub public, `titilyonnais/MacDock`. Chaque
version est un installateur `.exe`, construit et publié par GitHub Actions. La mise à jour automatique fait l'objet du
plan 53 ; ce plan pose la version, l'installateur et les publications sur lesquels elle s'appuie.

## Choix de l'utilisateur (9 octobre, au réveil)
- Dépôt **public** `titilyonnais/MacDock`, licence **MIT** (titulaire : `titilyonnais`).
- **Installateur .exe** (Inno Setup), construit par GitHub Actions à chaque version.
- Son prénom et son dossier utilisateur retirés **de tout l'historique** avant le premier envoi : historique réécrit,
  sauvegarde complète gardée (`git bundle`).

## Choix
- **Version** : `MAJEUR.MINEUR.CORRECTIF`, le mineur étant le dernier plan fusionné (0.52.0 pour ce plan). Une seule
  source, `src/core/version_defs.h` (macros), lue par le C++ (`kMacDockVersion`, À propos) et par les ressources
  `VERSIONINFO` des quatre exécutables (Propriétés > Détails de Windows). La publication vérifie que l'étiquette `vX.Y.Z`
  correspond à cette version.
- **Installateur** (`installer/MacDock.iss`) :
  - **installation** : par utilisateur, sans droits d'administrateur, dans `%LOCALAPPDATA%\Programs\MacDock` ;
  - **contenu** : les quatre exécutables, le dossier `windhawk` (l'app Réglages y trouve les mods), `LICENSE` et `README.md` ;
  - **menu Démarrer** : MacDock (le lanceur) et Réglages MacDock ;
  - **démarrage avec Windows** : coché par défaut, même valeur `Run\MacDock` que `MacDockLauncher.exe --install` ;
  - **avant de copier** : MacDock est quitté proprement (`MacDock.exe --quit`, puis attente de ses fenêtres) ;
  - **après** : relancé, même si l'installation échoue ;
  - **paramètres d'essai** : `/NOLAUNCH` et `/NOSTARTUP`, ni lancement ni démarrage automatique ;
  - **désinstallation** : MacDock quitté et démarrage retiré ; les réglages de `%APPDATA%\MacDock` sont gardés, comme sur macOS.
- **GitHub Actions** :
  - `ci.yml` (à chaque envoi sur `main`) : build Debug et Release, tests ;
  - `release.yml` (étiquette `v*`) : build Release, étiquette comparée à la version, Inno Setup (Chocolatey s'il
    manque), installateur `MacDock-Setup-X.Y.Z.exe` et `SHA256SUMS.txt` joints à une release GitHub.
- `build.ps1` : SDK 10.0.26100.0 s'il est installé, sinon celui par défaut de Visual Studio (machines de GitHub).

## Revue : points d'attention
- Une mise à jour installée par-dessus MacDock en marche : rien de verrouillé, MacDock relancé ensuite.
- Installation ratée ou annulée : MacDock revient quand même.
- Aucune donnée personnelle dans le dépôt public (historique compris), aucun secret dans les workflows.
- Le démarrage avec Windows suit l'emplacement installé, pas l'ancien `build\Release`.
