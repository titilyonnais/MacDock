# Effet génie (plan 10) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Réduire une fenêtre la fait s'écouler dans sa miniature du Dock (effet génie ou échelle), et la restaurer depuis le Dock la fait ressortir.

**Architecture:** Géométrie pure (`src/anim/genie.*`) qui découpe la fenêtre en bandes ; à l'écran, une fenêtre transparente du Dock (`GenieWindow`) affiche une miniature DWM par bande ; le Dock déclenche l'animation à la réduction et au clic sur la miniature, et coupe l'animation de Windows (`MinAnimateGuard`) sans toucher au profil.

**Tech Stack:** C++ (MSVC `/std:c++latest`), Win32, DWM (`DwmRegisterThumbnail`), `SystemParametersInfo`, minitest.

**Spec:** `docs/superpowers/specs/2026-10-07-genie-design.md`

## Global Constraints

- Aucune ressource Apple.
- Les tests ne changent aucun réglage de Windows : `MinAnimateGuard` reçoit des fonctions factices ; aucun test n'appelle `SPI_SETANIMATION`.
- Aucun essai réel qui affiche une fenêtre ou pilote la souris ou le clavier ; ne jamais lancer `MacDock.exe` sans `--snapshot`/`--genie-snapshot` pendant que l'utilisateur travaille.
- `SPI_SETANIMATION` sans `SPIF_UPDATEINIFILE` ; valeur d'origine lue dans `HKCU\Control Panel\Desktop\WindowMetrics\MinAnimate` (défaut 1).
- `minimizeEffect` : `genie` (défaut), `scale`, `windows` ; valeur inconnue → `genie`.
- Durées : génie 0,55 s, échelle 0,3 s, × 8 avec Maj.
- Fichiers en UTF-8, fins de ligne LF.

## Review Focus

1. Fenêtre agrandie puis réduite : le départ doit couvrir la zone de travail (pas `rcNormalPosition`), sinon l'animation part d'un rectangle faux.
2. Dock à gauche ou à droite : les bandes sont des colonnes, et la colonne la plus proche du Dock va en premier dans la case — inversion facile.
3. Plantage ou arrêt brutal du Dock : `iMinAnimate` reste à 0 pour la session ; un Dock relancé ne doit pas prendre 0 pour la valeur d'origine (registre, pas `SPI_GETANIMATION`).
4. Restauration ou fermeture de la fenêtre pendant son animation : l'animation s'arrête, aucune miniature ne reste à l'écran.
5. Écran à 200 % et case du Dock minuscule : bandes de 0 px (division par zéro, rectangles inversés).

namespace {
const RECT kWin{100, 100, 900, 700};   // 800 x 600
const RECT kTile{1500, 1040, 1548, 1076};
const SIZE kSrc{800, 600};

bool contiguous(const std::vector<md::GenieSlice>& s, bool vertical) {
    for (std::size_t i = 1; i < s.size(); ++i) {
        if (vertical ? s[i].dst.top != s[i - 1].dst.bottom : false) return false;
        if (s[i].src.top < s[i - 1].src.top && vertical) return false;

    return true;
}

`genie.h` inclut `<windows.h>`, `<vector>`, `../config/settings.h` (pour `DockPosition`). `genie.cpp` :
- `easeInOut(x)` = `x < 0.5 ? 4x³ : 1 − (−2x+2)³/2` ; `smooth(x)` = `x²(3−2x)` ; `clamp01`.
- Repère local : `toLocal(RECT, edge)` → `{u0,u1,v0,v1}` (bas : `u=x, v=y` ; gauche : `u=y, v=−x` donc `v0 = −right, v1 = −left` ; droite : `u=y, v=x`). `toScreen(u0,u1,v0,v1,edge)` → `RECT` (gauche : `left = −v1, right = −v0`, `top = u0, bottom = u1`).
- Source le long de `v` : bas → lignes `[0,src.cy]` ; droite → colonnes croissantes ; gauche → colonnes décroissantes (fraction `f` → `x = src.cx·(1−f)`).
- Génie : `n = min(slices, extent)` (extent = `src.cy` en bas, `src.cx` sinon) ; `p`, `q`, `w(v)` comme la spec (si `b0 ≤ v0`, `w = 1`) ; pour la bande `k`, frontières de destination `vk = lround(lerp(top, bottom, k/n))` pour que les bandes soient jointives ; largeur au milieu ; source `lround(extent·k/n)`.
- Échelle : `lerp` de chaque côté avec `easeInOut(t)`, `src` entière.
- `restoredRect` : agrandie → rectangle de taille `src` centré sur `work` (bordures invisibles) ; fenêtre outil → `rcNormalPosition` ; sinon `rcNormalPosition` décalé de `(work.left − monitor.left, work.top − monitor.top)`.
