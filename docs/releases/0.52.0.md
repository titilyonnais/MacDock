Première version publiée de **MacDock** : un Dock et une barre des menus façon **macOS 26 Tahoe** pour Windows 11.

## Installer
1. Télécharge **MacDock-Setup-0.52.0.exe** ci-dessous et lance-le. L'installation se fait pour ton compte, sans droits
   d'administrateur, dans `%LOCALAPPDATA%\Programs\MacDock`. MacDock démarre ensuite avec Windows (case décochable).
2. L'installateur n'est pas signé : Windows SmartScreen peut afficher « Windows a protégé votre ordinateur ». Clique sur
   *Informations complémentaires*, puis *Exécuter quand même*.
3. Pour cacher la barre des tâches de Windows, installe le mod Windhawk décrit dans le README.

`SHA256SUMS.txt` donne l'empreinte de l'installateur.

## Ce qu'il contient
- **Dock** : agrandissement, rebonds, effet génie, piles, Corbeille, Spotlight, Mission Control, écran Apps,
  sélecteur d'apps, coins actifs.
- **Barre des menus** : menus de chaque app, icônes d'état, Centre de contrôle, Centre de notifications, volume et
  luminosité.
- **Fenêtres** :
  - feux tricolores sur toutes les fenêtres ;
  - menu de la pastille verte et « Déplacer et redimensionner » : moitiés, quarts, Organiser, Remplir, Centrer.
- **Coup d'œil**, captures d'écran (⊞⇧3, ⊞⇧4, ⊞⇧5) et sons du système.
- **App Réglages MacDock** pour tout régler.

Aucune ressource Apple n'est incluse. Si SF Pro est installée, MacDock l'utilise.
