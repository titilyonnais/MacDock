**MacDock se met à jour tout seul.** À partir de cette version, tu n'as plus rien à réinstaller.

## Installer
- **Première fois sur un PC, ou depuis la 0.52.0** : télécharge **MacDock-Setup-0.53.0.exe** ci-dessous et lance-le.
  L'installation se fait pour ton compte, sans droits d'administrateur. Windows SmartScreen peut demander
  *Informations complémentaires*, puis *Exécuter quand même* (l'installateur n'est pas signé par Microsoft).
- **Ensuite** : rien à faire, MacDock se met à jour lui-même.

## Mises à jour automatiques
- MacDock cherche les nouvelles versions sur GitHub une minute après le démarrage, puis deux fois par jour.
- Une version trouvée est téléchargée et vérifiée en arrière-plan, puis une notification propose de redémarrer
  MacDock pour l'installer. Sans clic, elle s'installe au prochain démarrage.
- Chaque version est signée par l'auteur (`SHA256SUMS.txt.sig`) : MacDock refuse toute version mal signée ou
  altérée.
- Réglages MacDock > À propos > Mise à jour de logiciels : *Rechercher*, *Installer*, et *Rechercher automatiquement*.

## Aussi
- **Pastille verte** : son menu au survol, comme macOS 26 (moitiés, quarts, Remplir, Centrer, Organiser, Plein écran).
- **Menu Fenêtre** : *Organiser* range la fenêtre active avec les suivantes.
- L'installateur arrête et relance MacDock proprement ; s'il échoue, l'ancienne version revient.
